        2. Auto-Publish 1-Klik ke GitHub Pages

        Data Embedded

        Perbarui file data.json di repositori GitHub Anda lewat GitHub API tanpa mengedit index.html lagi. Dalam ±30 detik, semua pengunjung langsung melihat data terbaru.

        Panduan Buat GitHub Token (1 Menit — Cukup Sekali Saja)
        1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → klik Generate new token.
        2. Pilih Repository access → Only select repositories, lalu pilih repository dashboard KPI Anda.
        3. Di bagian Repository permissions, ubah Contents menjadi Read and write, lalu klik Generate token.
        4. Salin tokennya, tempel di kolom Token di atas, lalu klik Simpan Pengaturan. Token hanya disimpan di browser Anda sendiri dan hanya dipakai untuk meng-update data.json.
